# System32 — Sistema de Agendamento Médico

Sistema web para gerenciamento e agendamento de consultas médicas, desenvolvido pela Software House System32.

## Software House

A **System32** é uma software house voltada ao desenvolvimento de sistemas gerenciais para hospitais, clínicas e consultórios que necessitam de soluções funcionais, intuitivas e práticas para melhorar o relacionamento entre pacientes e profissionais de saúde.

## Problema

Clínicas e consultórios podem enfrentar dificuldades na organização manual de pacientes, médicos, horários e consultas. Isso pode causar conflitos de agenda, atrasos no atendimento, perda de informações e dificuldade de comunicação entre paciente, recepção e médico.

## Público-alvo

- Hospitais, clínicas e consultórios médicos;
- Pacientes que precisam agendar ou acompanhar consultas;
- Recepcionistas e secretários responsáveis pela agenda;
- Médicos e demais profissionais de saúde;
- Administradores responsáveis pelo gerenciamento do sistema.

## Objetivo

Desenvolver uma aplicação web que centralize e simplifique o agendamento de consultas, oferecendo uma experiência prática para pacientes e uma gestão organizada para os estabelecimentos de saúde.

## Funcionalidades planejadas

- Cadastro e autenticação de usuários;
- Cadastro de pacientes, médicos e especialidades;
- Consulta de horários disponíveis;
- Agendamento, confirmação e cancelamento de consultas;
- Gerenciamento da agenda médica;
- Consulta do histórico de agendamentos;
- Painel administrativo.
